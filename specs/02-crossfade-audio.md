# 02 — Crossfade & Audio Transition Effects

## Current State

- Crossfade implemented in `daemon.rs:handle_audio_event()` with a single `load_standby`/`start_crossfade` call
- Default duration: 5s (PROMPT.md requests 7s)
- No easing options
- No reverb on transitions
- No volume dip on pause/resume

## Requirements (from PROMPT.md)

### Crossfade Defaults
- Default duration: **7 seconds**
- Every track transition (manual or automatic) triggers crossfade

### Easing Options

User-friendly names for crossfade curves:

| Name | Curve | Description |
|------|-------|-------------|
| Linear | `t → t` | Equal fade in/out |
| Slow fade in, fast fade out | `fade_in: t², fade_out: 1-√t` | Outgoing fades quickly, incoming builds slowly |
| Fast fade in, slow fade out | `fade_in: √t, fade_out: 1-t²` | Incoming snaps in, outgoing lingers |
| Log/Exponential | `fade_in: 1-2⁻ᵗ, fade_out: 2⁻ᵗ` | Natural-sounding analog style |
| Tempo ramp | tempo adjustment + gain fade | Outgoing track tempo increases during fadeout |

### Reverb on Transitions

Apply a convolution reverb to the fading track during crossfade:
- Short room reverb (IR length ~0.5s) for standard transitions
- Can be toggled on/off per transition type (manual vs auto-advance)

### Volume Dip on Pause/Resume

When the user presses pause:
1. Ramp volume from current → 0 over ~300ms (eased)
2. Pause the mixer backend
3. Store target volume

When the user presses resume:
1. Ramp volume from 0 → target over ~300ms (eased)
2. Unpause the mixer backend

This prevents abrupt audio cutoff.

### Unsafe Volume Warning

- Volumes above 85% require daemon confirmation
- Flow:
  1. Client sends `SetVolume { volume: 90 }`
  2. Daemon responds with `VolumeChallenge { session_id, unsafe_level: true }`
  3. Client shows warning prompt in TUI
  4. If user confirms, client sends `ConfirmVolume { session_id, volume: 90 }`
  5. Daemon verifies session_id matches, sets volume
- Session ID is generated by daemon on client connect, shared discreetly

## Easing Function Signatures

```rust
/// Easing curve for crossfade volume automation
pub enum Easing {
    Linear,
    SlowFadeInFastFadeOut,
    FastFadeInSlowFadeOut,
    Logarithmic,
    Exponential,
    TempoRamp,
}

/// Compute gain multiplier at normalized time t ∈ [0.0, 1.0]
pub fn ease_fade_in(t: f64, easing: Easing) -> f64;
pub fn ease_fade_out(t: f64, easing: Easing) -> f64;
```

## Crossfade Sequence

```
Track A playing (active player)
      │
      ├── Near end (within fade_duration + 0.5s)
      │     │
      │     ├── Load Track B on standby player
      │     ├── Start crossfade:
      │     │   fade_out(A) = ease_fade_out(t, easing)
      │     │   fade_in(B)  = ease_fade_in(t, easing)
      │     │   reverb(A)   = apply_reverb(A, reverb_amount * (1 - t))
      │     │
      │     ├── At t = 1.0:
      │     │   stop(A), play(B) full volume
      │     │   swap active/standby
      │     │
      │     └── Done
      │
      └── Manual skip (Next/Prev)
            │
            ├── Start crossfade immediately
            ├── Same easing as above
            └── Done
```
